## [1.0.0-capstone] - 2026-07-22

### Added
- **Block 00–04**: Complete engineering contract, product charter, system architecture, RBAC matrix, and screen inventory documentation.
- **Block 05–06**: Monorepo bootstrap (`apps/web`, `apps/ml-api`, `apps/worker`), design system (`packages/ui`), Plus Jakarta Sans typography, and PWA manifest.
- **Block 07–09**: Local Supabase platform configuration, PostgreSQL PostGIS schemas, RLS security policies, and server-side RBAC auth guards.
- **Block 10–12**: Public marketing landing page, role-specific application shells, and mobile-first citizen report wizard (`/reporter/laporan/baru`).
- **Block 13–14**: Durable Dexie IndexedDB offline queue (`mboyo-offline`), Workbox Service Worker caching, and Background Sync replay.
- **Block 15–17**: Private evidence upload with perceptual hash duplicate checks, short-lived signed URLs, and PostGIS location trust logic.
- **Block 18–21**: Governed ML dataset pipeline, calibrated EfficientNetV2/ConvNeXt benchmark, Grad-CAM explainability, and FastAPI ML API microservice.
- **Block 22–25**: Optional Gemini verifier advisory, Verifier human validation queue (`/verifier`), Coordinator Command Center (`/command`), and Web Push notifications.
- **Block 26–30**: Analytics & GeoJSON exports, Admin & Auditor governance portals, deterministic demo mode (`DEMO_MODE=true`), and Playwright E2E test suite.
- **Block 31–34**: Complete ops deployment runbooks, quality & accessibility audit, live presentation scripts, judge Q&A defense, and release hardening artifacts.
